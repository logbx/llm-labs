# LLM Labs

A structured knowledge base documenting AI-assisted software development workflows, tools, and experiments.

## Purpose

This repository serves as a living documentation system for:
- AI-assisted coding workflows and methodologies
- Tool evaluations and integration patterns
- Project initialization and planning templates
- Lessons learned and best practices
- Reusable prompts and templates for AI coding assistants

## Getting Started

### Prerequisites

This is a markdown-based knowledge base optimized for use with [Obsidian](https://obsidian.md/), but can be read with any markdown viewer or text editor.

**Optional but recommended:**
- [Obsidian](https://obsidian.md/) v1.0+ for wiki-style linking and graph view
- Git for version control

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/logbx/llm-labs.git
   cd llm-labs
   ```

2. **Open in Obsidian (optional):**
   - Launch Obsidian
   - Click "Open folder as vault"
   - Select the cloned `llm-labs` directory

3. **Browse without Obsidian:**
   - Navigate through folders using any file browser or IDE
   - All content is in standard Markdown format

### Usage

Start with these key documents:
- [`workflows/current.md`](workflows/current.md) - Current active workflow
- [`workflows/project-initialization.md`](workflows/project-initialization.md) - How to start a new AI-assisted project
- [`templates/README.md`](templates/README.md) - Available templates and their use cases

## Key Features

### Project Initialization Workflow
A 3-step process to go from idea to implementation-ready:
1. Gather project context and scope
2. Multi-AI tech stack validation (ChatGPT, Claude, Grok, Perplexity)
3. IDE-generated PRD with validated decisions

See [`workflows/project-initialization.md`](workflows/project-initialization.md) for details.

### Reusable Templates
- PRD generation prompts (optimized for Cursor and Claude)
- Tech stack validation prompts
- Tool evaluation templates
- Workflow documentation templates

Browse all templates in [`templates/`](templates/).
